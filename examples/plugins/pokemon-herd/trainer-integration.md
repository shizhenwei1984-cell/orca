# Trainer integration

`trainer.read({ terminalIds })` retains the work totals, wallet, candy, and current companions. A companion with a regional form or beyond the built-in sprite list also has a display name. `trainer.game({ terminalIds, query? })` returns the trainer pages. The optional Box query takes `page`, `search`, `sort`, and `filter`.

`trainer.command({ client, sequence, terminalIds, action })` accepts a 36-digit lowercase hex client ID and a positive, increasing sequence. Retry a lost response with the same envelope. The worker commits the receipt alongside the save. The last sequence for each client returns its saved result, and older sequences are ignored. Resolve each Pokémon from the latest snapshot's `ref`, which includes both its slot and its identity. After an action succeeds, reread the view. `trainer.changed` carries no state. It tells panels to reread the committed save.

## Worker contracts

- Pass `registerEncounterHandlers`, `encounterTrainerAction`, and `settleEncounterWork` to the named `activateTrainer(orca, extensions)` function in `worker.mjs`. The default worker entry supplies these extensions and starts the trainer. The registered handler receives `{ store, getScope }`. `store.transact(apply)` serializes actions and status events. Return `{ save, result }` from `apply`. It may run again after a storage error, so keep all durable effects and receipts in the returned save. `store.read(view)` waits for the writer. Call neither store method from inside a transaction.
- `getScope(save, ids, catalog, { fresh?, requested? })` returns `{ slots, closed, workspaceId }`. Pass the catalog from the transaction callback. The scope uses the ID from `workspace.list` for a named workspace or when the live targets share one. The Box also shows raised Pokémon when the worker can confirm the terminal closed.
- Some shipped hosts send a worktree identity for a folder project whose listed ID is raw. The worker checks the raw ID and host against `workspace.list`. It uses a status event or an older save that recorded both IDs to carry the encounter and work cursor to the listed ID in the same write. The pane slots and action receipts stay valid. If both room keys already exist, the listed room's encounter takes precedence and the highest work cursor for the latest day is retained. An older folder ID stays in the save until the worker can associate it with a listed workspace.
- `settleEncounterWork(before, after, { at, slots, workspaceId, rnd })` runs only when a status edge or a minute sample credits work. Compute new work from the difference in `daily.count.work`. Use zero for the previous count at a day boundary. A status edge subtracts `run.credited` from its completed segment. The minute timer checks the host still reports the same run, then processes each workspace in order before publishing the combined save.
- `trainer-game.mjs` exports `resolvePartyMember(save, terminalId)` and adapters `trainerPick` and `savedPokemon`. The trainer save keeps `jobs` as completed agent jobs and `stageJobs` as evolution progress. Upstream reads the latter as `pick.jobs`. Use the adapters before passing party data to encounter rules.
- `changeItems(save, signedCounts)` applies inventory deltas with upstream limits. It returns null if an item spend would exceed stock. `registerCaught(save, pick, id, at, slots, options)` inserts a caught pick in the Box with its Pokédex record and pays threshold rewards. Supply a namespaced stable event ID that never overlaps pane keys. It counts Research by default. Pass `{ research: false }` if the encounter delta already carries that event. Use `registerSeen`, `creditResearch`, and `settleBadges` in the same transaction.
- The storage index is the only publication point. The worker writes compressed chunks to the other bank before replacing the index. Legacy raw snapshots keep their balances, grants, and pause state. The worker excludes the obsolete pay remainder from future jobs. Keep writes to trainer storage inside the worker.

## Feature ledger

| Feature       | Trainer behavior                                                                                                      | Integration                                                                                                                            |
| ------------- | --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Bag and Shop  | Upstream prices, quantity caps, half-price sales, item exchange, and timed boost inventory                            | Call items, Poké Ball and bait preferences, festival effects, and the boosts' world behavior need encounter or world wiring            |
| Party and Box | Give and take held items, feed berries, rename, lock, release with undo, release duplicates, purify, and move Pokémon | The `choose` command accepts the picker selection. A Tower switch or battle heal uses the encounter extension before commit            |
| Evolution     | Job, friendship, day or night, stones, Rare Candy, forms, and region maps use upstream rules                          | The baseline field renders only its original starter sheets. The catalog supplies other art                                            |
| Day Care      | Pair Pokémon from the Box and use work minutes for eggs, warm abilities, and hatching                                 | The move and ability tables are shared with encounters                                                                                 |
| Research      | The daily draw and automatic payouts include work, job, quick reply, pet, and berry events                            | Enable visitors in the save when the encounter adapter supplies catch and gift. Spar needs the encounter event                         |
| Badges        | All eight goals, held item gifts, and Shiny Charm progress                                                            | Apply `trainerPerks` to encounter and world rules. Persist trainers beaten under `bag.marks.trainers` and Tower best under `towerBest` |
| Pokédex       | Regional totals, seen and caught species, shiny, Alpha, gender, size records, and catch rewards                       | Use the registration functions on visitors, catches, and evolutions. A picker selection registers as seen                              |
